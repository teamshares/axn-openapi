## Development

- `bin/setup` — install dependencies (and the Rails dummy app's, if present).
- `bin/refresh` — pull latest and install dependencies (fails on a dirty working tree).
- Before pushing: `bundle exec rake` runs the Rails-free specs + rubocop; run `bundle exec rake verify` to also run the Rails dummy-app suite (`spec_rails`) — required for any Rails-affecting change.
